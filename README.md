# Build What Moves India

Working repository for the **Build What Moves India** hackathon.

## Current status

The project is in the problem-discovery phase. No government website, public service, target user journey, solution architecture, or technology stack has been selected yet.

The current research treats Indian public-service websites as a broad problem space. The hackathon's final submission must later narrow this into one real user problem and an end-to-end working prototype.

## Repository structure

- `docs/` — committed project status and decision records.
- `prompts.md` — append-only ledger of prompts used for this project.
- `research/` — private raw notes, source reviews, and synthesis; intentionally ignored by Git.

Implementation folders will be created only after the specific service problem and technical direction are chosen.

## Working principles

- Do not assume the final government service or website before evidence-based selection.
- Solve a user journey, not merely a visual redesign.
- Treat accessibility, low-bandwidth performance, mobile use, language, security, privacy, and maintainability as core requirements.
- Use only mock or synthetic sensitive data during the hackathon.
- Clearly distinguish verified facts, user reports, hypotheses, decisions, mocks, limitations, and future work.
- Keep Codex/OpenAI usage meaningful and record the prompts used.

## Source of truth

The current committed status is documented in [`docs/project-status.md`](docs/project-status.md). Private research synthesis lives under `research/` and is not uploaded to Git hosting.
